## Windows

Get EchoDiar for Windows 11 (x64, Arm64) from the Microsoft Store: https://apps.microsoft.com/detail/9N5X564S1F2D?mode=direct. The Store installs it in one click and keeps it updated. Microsoft reviews each version, so the Store gets this one up to a few days after this release.

**Installed EchoDiar earlier with its certificate (`EchoDiar.cer`)?** Move to the Store as described at https://ed.dinhanhthi.com/docs.html#windows-warnings: your recordings and API keys stay. Until you move, that copy keeps updating from the Windows files in the Assets below; new installs use the Store.
